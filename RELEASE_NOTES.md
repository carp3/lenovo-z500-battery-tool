Experimental Lenovo Z500 battery monitor for Windows x64.

Includes live pack/cell readings, selectable graphs, decoded/raw searchable registers, tooltips, formatted JSON, and opt-in CSV logging. Calibration code is retained behind a default-off build flag; official release builds cannot issue calibration commands.

Only the fingerprint-matched BIOS/Lenovo driver combination documented in the README has been verified. No driver is bundled. Requires administrator elevation and .NET Framework 4.x. The executable is unsigned.

Download and extract the ZIP, then run Z500Battery.exe. SHA256SUMS.txt lists hashes for the ZIP and executable. Source and build instructions are in the repository; executables are distributed only as release assets.
